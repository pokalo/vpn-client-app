# VPN Smart Client — Ручное подключение на iPhone (IKEv2)

> Передача файлов в РФ не нужна: всё ставится прямо с телефона в Safari.

Сервер: `69.12.73.250`, протокол IKEv2 (UDP 500/4500), strongSwan.
Работает в РФ — блок касается только TLS/SNI, IPsec-трафик по UDP проходит (протестировано).

---

## ШАГ 1. Установи доверенный сертификат (один раз)

Открой в **Safari** на iPhone ссылку:

```
http://69.12.73.250/vpn-ca.cer
```

1. iOS покажет уведомление **«Профиль загружен»** → нажми на него.
   - Если не появилось: **Настройки → Основные → Профиль** (или «VPN и управление устройством»).
2. Нажми **«Установить»** → введи пароль экрана → «Установить» → «Готово».
3. Теперь **обязательно** включи доверие сертификату:
   **Настройки → Основные → О программе → Параметры доверия сертификатам**
   → переключатель напротив **VPN Smart Client CA** → «Полное доверие».

> Это критично. Без полного доверия iOS подключится, но через пару минут
> разорвёт соединение с ошибкой проверки сертификата.

---

## ШАГ 2. Добавь VPN вручную

1. **Настройки → Основные → VPN и управление устройством → VPN**
2. (Если VPN уже есть) нажми **«Изменить»** или карандаш.
3. Нажми **«Добавить конфигурацию VPN…»** или значок **«+»**.
4. Заполни:

| Поле | Значение |
|---|---|
| Тип | `IKEv2` |
| Описание | `VPN Smart Client` |
| Сервер | `69.12.73.250` |
| Удалённый ID | `69.12.73.250` |
| Локальный ID | `iphone` |
| Аутентификация | без сертификата (None) |
| Имя пользователя | `iphone` |
| Пароль | `S8fXb2kQm4pW` |

5. Нажми **«Готово»** (сохранить).

> Поля «Удалённый ID» и «Локальный ID» **обязательно заполнить** — без них
> iOS не подключается к strongSwan.
> Если iOS требует выбор сертификата в поле «Certificate» — выбирай «None/Без».

---

## ШАГ 3. Подключись

1. **Настройки → VPN** → тумблер **VPN Smart Client** → ON.
2. При появлении запроса доверия сертификату → **«Доверять»**.
3. Иконка **VPN** в статус-баре — соединение активно.
4. Проверь IP: открой в Safari `http://ifconfig.me` — должен показать `69.12.73.250`.

---

## Если что-то не работает

| Проблема | Решение |
|---|---|
| «Сертификат не доверен» | ШАГ 1, п.3 (полное доверие не включено) |
| «Нет подключения» / висит 30 сек | Проверь что поле **Удалённый ID** = `69.12.73.250` |
| Подключился, но через 1–2 мин отвалился | Снова включи полное доверие CA из ШАГ 1 |
| Хочешь новую ссылку проверить | Открой `http://69.12.73.250` в Safari (порт 80 работал в РФ) |

## Что ещё можно скачать по ссылке (опционально)

- Корневой сертификат (pem): `http://69.12.73.250/vpn-ca.pem`
- Полный автоконфиг: `http://69.12.73.250/VPN_Smart_Client.mobileconfig` (если понадобится)

> Автоконфиг `.mobileconfig` — это файл настроек, который ставится в один тап
> (всё из ШАГ 2 прописывается автоматически). Если ваша сеть его пропускает,
> то инструкция выше работает так же.
